Publishing, following your hosting guide:
1. Create a public GitHub repository named YOUR-USERNAME.github.io and add a README.
2. Upload index.html, style.css, and the images folder directly to the repository root (not the ZIP or enclosing folder).
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait for successful deployment and open the URL shown in Pages.
5. Verify the photo, styling, and navigation, then submit the live website URL.
